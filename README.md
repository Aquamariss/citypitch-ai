# Citypitch-AI

Онлайн-тренажёр питчинга городских проектов АНО «Городской университет 2.0». Пользователь готовит текст питча с ИИ-наставником, наговаривает его голосом и получает разбор: соблюдена ли структура, уложился ли он в тайминг, насколько связна и убедительна речь.

## Методика

Питч состоит из девяти блоков и звучит около 10 минут:

| № | Блок | Ориентир |
|---|------|----------|
| 1 | Представление | 45 сек |
| 2 | Проблема | 1 мин 15 сек |
| 3 | Доказательства | 1 мин |
| 4 | Идея | 1 мин 30 сек |
| 5 | Ценность и эффект | 1 мин 30 сек |
| 6 | Показатели | 1 мин 15 сек |
| 7 | Команда | 1 мин |
| 8 | Следующий шаг | 1 мин |
| 9 | Запрос | 45 сек |

Время блоков — **рекомендация для подготовки**: оно попадает в подсказки и в текстовую обратную связь, но на оценку не влияет. Короткий блок не считается недостатком, если содержание закрыто честно для текущей стадии проекта.

Оценка складывается из пяти критериев:

| Критерий | Вес | Кто считает |
|----------|-----|-------------|
| Структура — раскрыты ли девять блоков | 30% | разметка ИИ + код |
| Тайминг — общая длительность против 10 минут | 20% | код |
| Логика и связность | 20% | ИИ |
| Убедительность и подача | 15% | ИИ + счётчик слов-паразитов |
| Ясность и доказательность | 15% | ИИ |

Порог зачёта — 60%. Уложиться раньше времени не штрафуется; штрафуется только превышение 10 минут, а на 12 минутах запись останавливается автоматически.

**Вся методика живёт в одном файле — [`config/pitch_methodology.php`](config/pitch_methodology.php).** Оттуда она расходится в промпты, скоринг, Pitch Writer и интерфейс. Чтобы изменить структуру, тайминги, критерии или веса, правьте только его.

## Возможности

- **Pitch Writer** — чат с ИИ-наставником и черновик питча по девяти блокам с оценкой времени звучания
- **Студия записи** — запись аудиопитча в браузере с подсказкой по структуре и предупреждениями о таймингe
- **Разбор** — распознавание речи, разметка по блокам, оценка по критериям, приоритетные правки
- **История** — прошлые попытки и динамика баллов
- **Вход по OTP** — авторизация по коду на email

## Как устроен разбор

1. Запись уходит в очередь (`ProcessPitchJob`).
2. `TranscriptionService` распознаёт речь и возвращает сегменты с таймкодами (модель — `PITCH_TRANSCRIPTION_MODEL`, по умолчанию `whisper-1`: она отдаёт таймкоды, без которых не собрать разметку).
3. `PitchSegmentationService` раскладывает расшифровку на девять блоков: раскрыт / вскользь / не прозвучал.
4. `PitchAnalysisService` оценивает содержательные критерии по уже размеченному тексту.
5. `PitchScoringService` считает тайминг, структуру и слова-паразиты кодом и собирает итоговый балл по весам методики.

Баллы за структуру и тайминг модель не выставляет — они детерминированы и покрыты тестами.

## Стек

| Слой | Технологии |
|------|------------|
| Backend | Laravel 13, PHP 8.5, MySQL, Redis, queues |
| Frontend | Inertia.js, Vue 3 + TypeScript, Vite, Tailwind CSS 4 |
| AI | OpenAI-совместимый API (чат, распознавание речи, анализ) |
| Dev | Laravel Sail (Docker) |

## Требования

- Docker и Docker Compose
- [Laravel Sail](https://laravel.com/docs/sail) (через Composer)

## Быстрый старт

```bash
cp .env.example .env
composer install
./vendor/bin/sail up -d
./vendor/bin/sail artisan key:generate
./vendor/bin/sail artisan migrate
./vendor/bin/sail npm install
./vendor/bin/sail npm run build
```

В `.env` укажите ключ провайдера:

```env
OPENAI_API_KEY=sk-...
# при необходимости:
# OPENAI_BASE_URL=
```

Приложение: [http://localhost](http://localhost) (порт задаётся `APP_PORT`).

Для локальной разработки с hot reload:

```bash
./vendor/bin/sail npm run dev
./vendor/bin/sail artisan queue:listen
```

или `composer run dev` внутри контейнера (сервер + queue + Vite).

## Полезные команды

```bash
./vendor/bin/sail artisan test          # тесты
./vendor/bin/sail bin pint --dirty      # стиль PHP

./vendor/bin/sail artisan migrate       # миграции
```

## Основные экраны

| Маршрут | Назначение |
|---------|------------|
